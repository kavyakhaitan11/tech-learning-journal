### ☁️ Cloud & Infrastructure

* **API (Application Programming Interface):** A digital bridge or waiter that allows two different software programs to talk to each other and exchange data.
* **Open Source:** Publicly accessible software code that anyone can inspect, modify, enhance, and learn from.

### 💻 Development Fundamentals

* **Repository (Repo):** A digital folder or storage space where all the files, history, and revision logs of a project live.
* **Version Control:** A system (like Git) that tracks changes to files over time so you can recall specific versions later if something breaks.
